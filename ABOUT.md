# About / 关于

中文优先：

PocketRelay 是一个私人跨设备内容中转站，用来把手机上的文字、链接、代码和图片快速推到电脑面前。它运行在 Cloudflare Workers、D1 和 R2 上，支持客户端加密归档、iOS Shortcuts 推送入口和可选访问口令。

English:

PocketRelay is a private cross-device content relay for moving text, links, code snippets, and images from your phone to your desktop. It runs on Cloudflare Workers, D1, and R2, with client-side encrypted archives, an iOS Shortcuts endpoint, and an optional site-wide access password.
