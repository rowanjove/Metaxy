# About / 关于

中文优先：

之间门是一个私人跨设备内容中转站，用来在手机、平板和电脑之间临时传递文本与多个文件。它运行在 Cloudflare Workers、D1 和 Private R2 上，支持短期提取码、自动过期清理、iOS 快捷指令和管理后台。

English:

Metaxy is a private cross-device relay for temporarily moving text and multiple files between phones, tablets, and computers. It runs on Cloudflare Workers, D1, and private R2 storage, with short-lived retrieval codes, automatic expiry, an iOS Shortcuts endpoint, and an admin console.
