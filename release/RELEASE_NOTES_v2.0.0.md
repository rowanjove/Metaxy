# Metaxy v2.0.0

Metaxy v2 将原来的卡片流重构为更明确的“创建草稿 → 写入文本/上传文件 → 提交 → 按提取码领取”流程，适合临时跨设备传递文本和多个文件。

## 本版亮点

- 一次中转可包含一段文本与最多 10 个文件。
- 单文件最高 50 MiB、单次文件总量最高 500 MiB、大文本最高 5 MiB。
- 文件直接上传 Private R2；校验后固化到独立正式对象，旧预签名链接无法覆盖已提交内容。
- 支持 10 分钟至 7 天有效期、实时过期判断、二维码分享和移动端布局。
- 新增管理后台、iOS 快捷指令接口、限流、就绪探针和两阶段自动清理。
- 覆盖上传重试、尺寸不符、链接重放、并发提交、Session 撤销和清理退避等回归测试。

## 升级提示

这是不兼容的主版本升级。请先备份远程 D1 和 R2，再依次执行：

```bash
npm ci
npm run db:migrate:remote
npm run deploy:dry
npm run deploy
```

部署前必须替换 `cors.json` 中的示例 Origin，并配置 README 列出的 Secrets 与 R2 生命周期规则。

旧版 `cards` 表不会自动迁移。确认 v2 功能与备份无误后，才可按需执行一次性的旧表删除脚本。
