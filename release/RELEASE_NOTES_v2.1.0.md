# 之间门 / Metaxy v2.1.0

本次功能版本完善 iOS 快捷指令与网页发送体验，并集中修复代码审查发现的安全性、上传可靠性和清理一致性问题。

## 更新内容

- iOS 快捷指令现在可直接提交图片和任意文件；请求体流式写入 Private R2，不会先把大文件整体读入 Worker 内存。
- 网页发送区文本框新增显式“粘贴”按钮，同时保留系统粘贴文本与剪贴板图片能力。
- 多文件上传在单个文件失败后继续处理剩余队列，重试前会优先确认上一次上传是否实际成功。
- 生产入口配置为 `https://drop.rowanjove.top`。

## 安全与可靠性

- 上传口令和快捷指令令牌在校验前按来源 IP 限流，错误凭据也不能绕过配额。
- 快捷指令文件上传校验声明大小，并在流式写入过程中阻止超限请求体。
- 管理后台延期仅会增加有效期，不会因系统上限变化意外缩短现有内容。
- 全局清理失败会让计划任务明确失败；快捷指令失败产生的草稿会进入待清理状态。

## 兼容性

- 保持现有文本快捷指令、网页上传、提取码与管理 API 兼容。
- 本版本不新增 D1 数据库迁移。
- 快捷指令仍是一请求一条内容；文件请求使用原始二进制请求体，并通过 Header 提供文件名与类型。

- 2 项 Playwright 端到端测试通过。
