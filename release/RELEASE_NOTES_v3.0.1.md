# 之间门 / Metaxy v3.0.1

本版本聚焦 Gallery 2.0 直传链路的并发安全、对象完整性和上线就绪检查。

## 主要更新

- 直传完成采用 D1 原子 claim，重复请求不会并行固化同一上传会话。
- 固化前验证 R2 实际大小、缩略图上限和 WebP/主图文件签名。
- `/api/v1/ready` 覆盖 Gallery 2.0 上传会话与相册表，避免迁移未完成却报告就绪。
- 过期清理覆盖已完成上传会话，补回 staging 删除失败后的清理机会。
- 加强 Gallery API 的 JSON、分页、批量、相册和元数据边界；取消中的前端任务不会被异步请求误标记为成功。

## 升级说明

- 需要执行 D1 迁移 `0008_gallery_v2.sql`，其中包含 Gallery 2.0 上传会话、相册及缩略图期望大小字段。
- 不需要重新创建现有 R2 Bucket 或修改已有 Secret。

## 验证

- 单元/集成测试、Workerd 测试、类型检查、生产构建和部署 dry-run 均应通过。
- 未用真实图片上传污染生产数据；线上仅验证健康、就绪、元信息和 WebDAV 未授权挑战。
