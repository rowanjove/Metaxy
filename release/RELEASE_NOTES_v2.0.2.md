# 之间门 / Metaxy v2.0.2

本次补丁版本发布全新的品牌图标，并同步更新项目截图与无障碍细节。

## 更新内容

- 重新设计原生 SVG 图标：相向的双门框形成字母 `M` 轮廓，中央亮色区域代表“之间”的通道。
- 使用蓝色到靛紫色渐变延续现有界面色彩，并针对 16px、32px 等小尺寸显示优化几何结构。
- 更新桌面端首页、移动端首页和内容详情页真实截图。
- 导航栏图标使用空替代文本，避免屏幕阅读器在相邻品牌名存在时重复朗读。

## 兼容性

- 不改变 API、数据库结构、Cloudflare 绑定或浏览器本地状态。
- 可以从 v2.0.1 直接升级，无需新增数据库迁移。

## 验证

- TypeScript 类型检查通过。
- 57 项单元与集成测试、3 项 Workerd/D1 测试通过。
- Playwright 端到端测试和生产构建通过。
- npm 依赖安全审计未发现漏洞。
- Release 源码包不包含本地 Secret、`.dev.vars`、构建缓存或 Wrangler 状态。
